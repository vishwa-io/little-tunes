# Little-tunes

A simple and cute music player built with React and Vite.

## Live Demo

https://little-tunes.vercel.app/

## Features

- Play and pause songs
- Previous and next song controls
- Displays the current song name
- Shows the current time and total duration
- Seek through song using the progress bar
- Automatically moves to the next song when a song ends

## Built With
- HTML5 Audio
- CSS
- JavaScript
- React
- Vite
